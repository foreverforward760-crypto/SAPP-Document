## Reading the evidence

The documents contain philosophical arguments and comparisons with other traditions, scientific theories, and psychological concepts. Similarities and analogies should not be treated as proof that the framework has been scientifically validated. Any empirical or clinical claim requires independent source verification and appropriate testing.

The framework documents are conceptual works. They do not, by themselves, establish validated clinical, psychological, physical, or predictive measurements.
